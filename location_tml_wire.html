지정호기 칸을 누르면 해당 바코드의 호기를 바꿀 수 있습니다. 여러 건은 왼쪽 체크 후 아래 버튼으로 한 번에 변경합니다.

24120 시트 (입고 내역)

…
  1. 엑셀 24120 시트에서 A열~L열 전체 데이터를 선택해 복사 (Ctrl+A → Ctrl+C)
  2. 아래 칸을 누르고 붙여넣기 (Ctrl+V)
  3. 인식된 행 수를 확인한 뒤 업데이트

LOCATION 시트 (자재별 지정장소)

…
  1. 엑셀 LOCATION 시트에서 A열~C열(자재코드·품명·지정장소)을 선택해 복사
  2. 아래 칸을 누르고 붙여넣기 (Ctrl+V)
  3. 인식된 행 수를 확인한 뒤 업데이트

0처리 내역 (사용완료 바코드)

…
  1. 0처리 내역 엑셀에서 바코드가 포함된 범위를 선택해 복사 (열 순서는 상관없음 — 바코드 열을 자동으로 찾습니다)
  2. 아래 칸을 누르고 붙여넣기 (Ctrl+V)
  3. 인식된 행 수를 확인한 뒤 업데이트

24120·LOCATION은 업데이트하면 붙여넣은 내용으로 전체 교체되고, 0처리 내역은 기존 내역에 누적됩니다. 바코드별 지정호기 기록은 그대로 유지됩니다.
